# Agent-assisted development review

The user requested agents as reviewers. Two fresh agents review the declared
batch with detector outputs and each other's judgments withheld. Their actual
IDs and exposure records remain separate. This is agent development evidence;
human annotation, agreement and usefulness are not inferred.

`selection.json` precedes source reads and labels. It selects six licensed
natural originals from development metadata: R005's original limited scope,
the next two untouched GitHub Docs candidates and the first three complete
Requests Python modules. Seven previously exposed source IDs/hashes stay
excluded. Original manifests and split freezes remain unchanged.

Two root-authored originals exercise sparse claim, repetition, documentation and
same-document-link cases. A third authored source has a pinned synthetic native
Git context and target bytes/inventory absence. `challenge-originals.json`
retains their exact UTF-8 text and hashes. The author knows the implementation;
these are a separate challenge population, not natural effectiveness samples.

`review-matrix.json` declares applicable rules and source scopes. `readings.json`
lists 30 directly linked readings, each at most 76 lines of 80 characters.
Canonical strings and source-coordinate rows are in `readings/`; text views stay
in temporary files. Complete selected Python modules supply static signature
and binding context. Reviewed modules are not executed or imported.

Frozen published guidance and rule-contract metadata contain no predictions.
Unexpanded GitHub content and unsupported renderer/return contracts retain their
limitations. The local-link cohort uses bound GitHub-style static Markdown;
reviewers inspect target text and inventory evidence before labeling links.

Each reviewer writes separate version 3 annotations and raw reasons. Validate
source bindings and coverage, report disagreements, and preserve any adjudication
before freezing accepted labels. Generate predictions only after that committed
freeze. Reports keep natural and authored populations separate and retain raw
unreviewed findings, misses, exclusions and unavailable metrics.

`licenses.json` retains pinned source license bytes, Requests NOTICE, full
attribution and project terms for authored materials. Cached natural originals
keep their exact source bytes. No reserved holdout prose is opened.

R005 remains human-unanswered. Its agent judgments do not become human answers.
The earlier human session, unanswered prompts and historical freezes remain
unchanged; the updated protocol records the user's delegation.
